# OrangeHRM Manual Testing Project 

## 1.About This Project 

This Project contains complete manual testing documentation for the OrangeHRM web application. OrangeHRM is an open source Human Resource Management system. The goal of this project is to test the core functionalities and find bugs through structured manual testing.

## 2.Application Details 

Application Name : OrangeHRM
Application Type : Web based HRMS 
URl              : https://opensource-demo.orangehrmlive.com
Admin Username   : Admin
Admin Password   : admin123
Testing Type     : Black box Testing 

## 3.Objectives 

- Verify all core modules work as per expected behavior
- Identify and document defects with proper severity
- Ensure application handles valid and invalid inputs correctly
- Validate navigation,error messages,and UI behavior
- Practice real world testing workflow

## 4.Modules Tested 

- Login Module : Authentication , validation , session handling
- Admin        : User management ,add,edit,delete,search
- PIM          : Employee records,add,search,update
- Leave        : Apply leave,date validation,leave list


## 5.Tools used 

- Browser: Google chrome(Latest)
- Documentation: Github Markdown
- Screen Capture: Snipping Tool
- Bug Tracking: Github Markdown Bug report

## 6.How to navigate This Project

- start with Test-Plan to understand scope and approach
- Go through Test-Cases module by module
- Execute each test case on the live demo site
- For every failed test case create a bug entry in Bug-Reports
- Take screenshots and save them in Screenshots folder
- Update the Test Summary and Bug Summary tables above
